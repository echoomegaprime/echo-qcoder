# Troubleshooting

| Symptom                          | Likely cause                                        | Diagnostic command                                                      | Expected evidence                                    | Corrective action                                                                     |
| -------------------------------- | --------------------------------------------------- | ----------------------------------------------------------------------- | ---------------------------------------------------- | ------------------------------------------------------------------------------------- |
| MCP initialization fails         | Server did not build or wrong transport             | `pwsh -File .\scripts\test-mcp.ps1`                                     | Health and `/mcp` result or preserved smoke log path | Rebuild, inspect the named log, and correct the first failing contract.               |
| Tool scan fails                  | Stale metadata or wrong resource                    | `Invoke-RestMethod https://mcp.echo-op.com/oauth-mcp-qcoder-v1/healthz` | Stable route returns health JSON                     | Deploy/fix the route, then Scan Tools again in a new chat.                            |
| Tool schema mismatch             | Host cached an earlier scan                         | `node .\scripts\validate-plugin.mjs`                                    | `tools=7` and contract valid                         | Rescan tools and start a new chat after validation.                                   |
| OAuth discovery fails            | Missing protected-resource/authorization metadata   | Inspect the well-known URLs documented by the authority                 | JSON metadata with exact resource                    | Publish correct metadata and preserve the `resource` parameter.                       |
| OAuth redirect mismatch          | Registered callback differs from host callback      | Check provider client registration                                      | Exact callback match                                 | Update the provider registration; do not loosen redirect matching.                    |
| Missing scope                    | Token lacks the tool scope                          | Inspect redacted auth error code                                        | `SCOPE_REQUIRED` and `insufficient_scope`            | Reauthorize with only the required scope.                                             |
| Wrong audience                   | Token issued for another MCP resource               | Check introspection claims server-side                                  | Exact QCoder resource audience                       | Correct resource binding and reauthorize.                                             |
| JWKS retrieval failure           | Applies only if switching from introspection to JWT | Provider/JWKS health check                                              | Valid bounded-cached key set                         | Restore provider reachability; fail closed meanwhile.                                 |
| UI does not render               | UI resource missing or host cached old URI          | MCP Inspector resource read                                             | `ui://qcoder/console/v1`, HTML MIME                  | Rebuild web, validate resource, and rescan.                                           |
| CSP rejection                    | New domain is undeclared                            | Browser console plus `node .\scripts\validate-plugin.mjs`               | Exact blocked origin and no wildcard                 | Add only the required exact origin or remove the dependency.                          |
| Widget bridge fails              | Malformed/unmatched JSON-RPC response               | `npm run test --workspace web`                                          | Bridge/state tests identify the case                 | Fix request matching; do not bypass validation.                                       |
| `plugin_asdk_app` ID missing     | ChatGPT registration has not completed              | `Test-Path .\.app.json`                                                 | False is expected before registration                | Register the live resource, copy the real ID, run `configure-app-id.ps1`.             |
| Local marketplace plugin missing | Staging/registration not refreshed                  | `pwsh -File .\scripts\install-local-marketplace.ps1`                    | Validated staging path                               | Run with `-Register` on a supported Codex build, then restart/refresh Codex.          |
| Write tools unsupported in host  | Account or host policy limits writes                | Invoke read tool, then inspect host limitation                          | Reads work; write blocked by host                    | Validate writes through Inspector and record host limitation; do not weaken security. |
| Temporary tunnel fails           | Tunnel expired or changed URL                       | Health request to its exact URL                                         | Non-200/timeout                                      | Recreate only for development; production uses stable HTTPS.                          |
| Production endpoint times out    | Edge, service, or FORGE path unavailable            | Check `/healthz`, `/readyz`, then service logs                          | First failing layer                                  | Recover that layer and rerun the staging-first protocol.                              |
| Submission validation error      | Private package lacks public artifacts              | Review `docs/SUBMISSION.md`                                             | Public submission is N/A                             | Do not submit until audience and external requirements change.                        |
